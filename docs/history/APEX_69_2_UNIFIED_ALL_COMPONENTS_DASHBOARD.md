# APEX 69.2.0 — Unified All-Components Dashboard

Adds a real APEX dashboard route at `/apex_os/all` (alias `/apex_dashboard`) that displays the high-use circled modules together on one responsive page:

- Mission Control
- Execution
- Analysis
- Chart
- Flow
- Story
- Levels
- Tape
- Replay
- Signal Log

The existing APEX top navigation remains available across the top, including Scanner, Terminal, Assistant, Flow/GEX, Trade Command, Operations, Execution OS, Morning Readiness, Status, and Health. `All Components` is added directly beside the APEX logo on the Institutional OS page.

The unified page is read-only and composes canonical APIs. It does not create a second intelligence engine, modify trade decisions, or gain execution authority.
