# APEX 41 — Adaptive Institutional Interface

## Purpose
Extend the APEX 40 workspace into a device-aware interface that changes presentation by screen size while preserving the existing analytics and route architecture.

## Included
- Phone, tablet, desktop, and ultrawide device modes
- Mobile five-tab bottom navigation
- Touch-first quick-action sheet and floating action button
- Edge-swipe sidebar opening and swipe-close behavior
- Larger touch targets on coarse-pointer devices
- Compact mode stored independently by device class
- Persistent desktop/tablet trade monitor
- Device-aware workflow preference persistence
- Safe-area support for modern phones
- Tablet/laptop collapsed navigation behavior
- Ultrawide spacing and monitor enhancements
- Existing Ctrl+K command palette, favorites, breadcrumbs, and workflow presets retained

## Deployment
Upload the changed files using their repository-relative paths. No database migration or new environment variable is required.
