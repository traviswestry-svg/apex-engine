# APEX 42 — Institutional Command Center

Adds `/command_center` and `/apex42` as a unified session workspace powered by existing APEX APIs.

## Features
- Unified institutional bias, execution, live intelligence, market structure, story, and risk panels.
- Context-aware orchestration modes: Auto, Open, Midday, Close, Review.
- Automatic panel prioritization by session phase.
- Mobile task-focused mode hides non-priority panels.
- 30-second refresh using existing `/api/institutional_os` and `/api/market_status` sources.
- APEX 40/41 shared navigation updated to make Command Center the primary Home destination.
- No new database, environment variable, or external dependency.
